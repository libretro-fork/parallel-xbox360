Borrowed SPIR-V linkage names, 2026-11-05
Baseline: complete 3a3c03c8024e32de8f7721ec02edffeea6a63229 archive.
Windows x64 GCC 16.2, -O2; native MSVC and WSL GCC sanitizer checks separately.

Each function drops its std::string prefix owner. Builder.addName returns the
immutable arena-owned OpName record; a linked function keeps a const byte view
and the prefix length up to '('. enterFunction passes that counted view into the
existing C89 string encoder. No temporary NUL-terminated prefix is constructed.
Null names retain empty linkage spelling. Names live in stable instruction slots
or nonmoving operand pages; later name allocations cannot relocate the view.
Functions retire before the module releases name instructions/payloads. Function
publication still follows all throwing name/block construction, with RAII only
at the typed interface. Direct Function factories no longer take caller strings;
repository direct callers are the detached-object tests, using LinkageType::Max.

GCC x64 sizes: Function 152 -> 136 bytes. Instruction 64, Block 136, Module 88,
and Builder 2000 are unchanged. The ordinary guest translator uses Max linkage,
so linked-name allocation savings below are not universal guest-path savings.
Ordinary functions still benefit from denser records and lower retained storage.
Other maps, vectors, strings, arena growth and driver compilation remain.

Construction: seven alternating quiet parent/current pairs, 1000 modules/sample,
73-byte helper names, warmed reusable workspace and output. Main is unlinked;
all remaining functions use either Max (plain) or Export (linked). Linked cases
also call enterFunction to emit the actual decoration. All C++ new and C operand,
arena, index, plan and output hooks are counted; allocator headers, allocator

its initial state. Timing excludes dump; untimed output bytes match. Earlier

function): 48.76% fewer calls, 60.73% fewer requested bytes, and 17.13% less median
construction time. The 71-function linked case is 13.62% faster. These are linked
synthetic fixtures, not gameplay or overall shader-compilation speedups. Plain
construction times are comparable with overlapping ranges; no universal timing
win is claimed. Plain largest retained storage falls 4608 bytes. Output allocation
counts are unchanged. Serializer throughput was not separately remeasured here.
