Implementation
--------------
Vulkan previously inherited empty ProcessCallInstruction/ProcessReturnInstruction
handlers. Calls now use the existing conditional-exec machinery and PC loop.
The call guard is emitted before OpSelectionMerge, preserving SPIR-V's immediate
merge/branch adjacency rule. Taken calls push CFindex+1; returns pop a dynamic PC
and reenter the same main-loop continuation. Real switch cases still reenter the
loop rather than falling through directly, preserving the NVIDIA workaround.

Only shaders marked uses_subroutine_calls allocate a uint4 return stack plus
uint depth. Four entries match the existing interpreter. Empty RET falls through;
call with full stack skips unchanged. DXIL previously saturated the depth but
shifted away a valid return address; it now skips without mutation too.
The fixed C89 SSA lowering borrows four local component IDs directly through the
existing builder callback adapter. There is no heap operand vector, host call
stack, new mutex, frontend handoff or audio scheduling change. Shader building
still uses the existing owned instruction arena; this is not zero-allocation
translation. Repeated rectangle-list invocations clear both stack and depth.
Reset clears the translator's state IDs before freeing its prior builder.

SpirvShaderTranslator::Modification::kVersion23 ->24 invalidates both Vulkan and
D3D12 persisted pipeline configuration keys. Existing shader cache data must
rebuild once so old silently incorrect subroutine output is not reused.

Limits
------
Vulkan modules were validated, not numerically executed on a physical Vulkan GPU.
The packed interpreter's golden results do not prove emitted Vulkan numerical
execution; they establish the intended guest semantics. C89 SSA execution tests
exercise stack lowering, not the whole renderer. No game/installed-DLL test,
visual graphics-accuracy claim, GPU timing, FPS or compilation-speed measurement
is made. Undefined/unbounded guest recursion beyond the four-entry stack is not
accepted as a reason to corrupt host or shader return storage. The broader
optimization and savestate goals remain incomplete.
