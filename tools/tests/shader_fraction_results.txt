Change
------
Vertex fractional parts on native-RTZ Vulkan devices previously expanded each
lane separately: explicit input FTZ, scalar Floor, repeated input FTZ around
subtraction and result FTZ. Now lend the whole scalar/vector input to one flush,
one lane-wise Floor and an uncontracted subtraction with both inputs known
clean. Floor of a flushed input cannot create a subnormal: its result is zero,
an integral normal value or non-finite. Keep output FTZ and native RTZ. No FMA,
reassociation, OpFract substitution, precision relaxation or skipped work.
Pixel lowering and devices without native RTZ retain their exact prior paths.

Production adds only typed SPIR-V interoperability/capability dispatch. No new
algorithmic C++ container, state map, allocation, request queue, lock, payload
copy or GPU/CPU roundtrip. Values remain borrowed IDs in the exclusive compiler
arena. The existing scalar reconstruction array is bypassed on this native path;
other compiler and driver storage/allocations remain. No runtime logging added.
