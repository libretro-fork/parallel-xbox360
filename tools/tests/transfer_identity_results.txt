Numeric-view identity transfer work (development branch; not release signoff)
==========================================================================
Scope
-----
Vulkan and D3D12 runtime dispatch select initialization-owned C89 banks for
matching color storage families0/1/2/3 (aliases10/12), without value conversion,
depth/stencil or host-depth sources. Gamma0/1 crossings are excluded, even
when both use RGBA8. Gamma16 retains its actual UNORM16 host view. Raw integer
ownership transfers continue to use their separate existing bank.

Keep original typed resources and descriptors. No extra image, integer alias,
intermediate color copy, worker queue or compilation wait is introduced.
Float fetch results reach float output directly; GPU typed-view conversions
are the same as the existing matching-format direct path. This does not
establish bit preservation for arbitrary NaN encodings in numeric views.

Four typed view classes share byte-identical shader modules for each shape.
Vulkan uses at most36 temporary modules and144/336 retained PSOs; D3D12 uses
at most36 modules and144 PSOs. Counts collapse at1x and unsupported/unused
view/sample combinations are omitted using actual device format support.
These are bounds, not measured startup latency or driver memory costs.

Only pitches, source-pitch reciprocal, tile base delta and physical sample
cross command storage (20bytes). C89 writers fill the unpublished destination
directly, with checked immutable metadata borrowed through return. All fixed
sample/scale/layout words are initialization constants, not repushed payload.
The shared address validator was extracted without changing its predicates.

Publication and coverage limits
-------------------------------
Publication requires the full exact-first-parent shader comparison and core
builds, in addition to these component checks; retain their evidence separately.
Preserve the existing reset/unload completion ordering. Source call-path review
and API-object lifetime tests above are not live-game reset/unload measurements.
Allocation observations cover payloads, retained storage, API object references
and process snapshots, not all emitter/driver internal allocation sizes.
Do not substitute warmed procedural results for cold-play coverage, loosen
limits, silently skip unavailable coverage or retry unchanged timings until
green. Mailbox and CI evidence must state actual coverage and limitations.

No game was run, no live shader cache was removed, no installed core changed.
Other draw-path compilation, accurate guest fallback and broader allocation/
thread/audio/I/O/serialization goals remain active and unresolved.
