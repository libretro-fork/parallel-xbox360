Stable C89 function/block pools and borrowed function names, Windows x64, 2026-11-05
Parent: complete 99291fe13 archive. Current: retained object pools in module arena.
GCC16.2 -O2 C++20 typed fixtures over production builder/allocator, seven alternating
parent/current pairs. Timing covers 1000 module constructions and destructions;
first complete module/output is untimed and warms all retained storage.
All three parent/current fixture outputs match byte-for-byte.

Runtime: per-worker pools retain 64-block and 32-function pages, aligned to 16 bytes.
Records are constructed in place, never copied, moved or cleared on warm reuse.
C++ glue runs real constructors/destructors; bitmap ownership catches detached
objects and constructor failures. Cleanup order is functions, remaining blocks,
then instruction payloads. Explicit typed owners retire their objects first.
Cold guest-worker and EDRAM setup reserve one page of each kind. Larger modules
may grow retained pages, so this does not eliminate every mid-game allocation.
Other metadata/operand/driver allocations remain; local fallback builders still
allocate/free their own pages. Pools are exclusive to one module/compiler worker.

Function input names borrow const char* instead of constructing a std::string
that linkage-free functions never use. Export/import spelling still owns the
required prefix. Debug SPIR-V name words still require their owned encoding.
Null names are supported. Failed/destroyed inline function IDs are unpublished
without resizing/copying the module index; partial parameters remain arena-owned.

Instruction 64 / Block 136 / Function 208 layouts unchanged. MinGW x64 Module 80->88,
Builder 2000->2008 bytes due to one opaque object-state pointer. Tags are separate
from object payloads. Cold default pages/state request 17630 additional bytes per
worker, excluding allocator headers. Pages grow to checked retained high-water
capacity and are released with the workspace, with no reset-time payload clearing.

Tracked counts include C++new and C arena/page/state/index/output/plan hooks;
operand malloc and allocator headers are excluded. Peak includes untimed golden
serialization, not OS RSS. Retained includes workspace plus output after module
destruction. All tracked heap returns to its initial value after workspace close.
