packet implementation now has its own C file and callback declaration. Production
sources no longer contain xe_spv_operands or include its header; the rebuilt
DLL's nm output contains no xe_spv_operands symbols. Historical comparison tools
may still select that source from an older complete revision, never the current
runtime. Existing packet allocator hooks and payload-pool behavior are preserved.

Module registration, packet lookup, type queries and checked pointer-storage
queries now operate on the C89 packet/index directly. The typed wrapper verifies
standard layout and first-member pointer interconvertibility. No new table,
packet copy, cache, owned buffer or allocation is introduced. Index borrow/reset
and arena ownership remain unchanged. Missing/non-pointer/empty records or an
ID-flagged storage operand fail without changing the C caller's output; the typed
wrapper asserts in debug and returns StorageClass::Max on release failure.

The control-flow/type builder graph in src/xenia/gpu/spirv remains. This is a real
storage/API deletion and a module-query migration, not completed directory
removal. Final Vulkan module assembly still copies ordered packets into a
contiguous buffer. Other growth/allocations and intermediary vectors remain.
