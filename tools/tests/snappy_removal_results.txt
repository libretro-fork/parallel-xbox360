Parent:26d55acff1c63b288ab6f021cc0cfc768de8adba

Removed third_party/snappy, its CMake and static-Make compile/link/include
entries and C89-generator configuration templates. Removed GPU trace capture,
protocol, Snappy adapters, custom VFS trace owner, screenshot writer, CVar and
CMake switches, callback APIs and caller parameters. Removed trace-only shared
memory/EDRAM downloads, buffers, ranges and recording hooks from Vulkan/D3D12.
Normal GPU uploads, memexport/resolve readbacks and snapshot restoration
primitives remain. This is removal of optional debugging machinery, not a claim
that all GPU copies disappeared or that normal Release gameplay is faster.
Trace-only fixtures/runners/CI steps were deleted with the feature. Upstream
exclusions cover the removed dependency and capture files. Historical optional
Snappy references in unused FFmpeg sources do not link the deleted dependency.
