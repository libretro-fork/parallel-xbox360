Added observations:
  Linux Vulkan module/PSO test intervals optionally capture process minor and
  major faults, voluntary/involuntary context switches, endpoint CPUs, process
  ID and before/after maximum RSS. Resource snapshots precede the existing
  start clocks and follow the existing end clocks. CSV formatting follows the
  snapshots. Normal release code and release build files are unchanged.
  The resource envelope is wider than the measured interval. An endpoint CPU
  match cannot exclude intermediate migration; switches or faults do not prove
  causality. Process CPU/rusage counters include worker threads. Maximum RSS
  is a process high-water mark, not live allocation or leak accounting.
  Each resource record is matched to its exact stage/case/sample; missing,
  excess or malformed records fail. These observations never suppress an
  elapsed-time failure. Timing cases and acceptance limits remain unchanged.
