Runtime scope
-------------
Vulkan and D3D12 now store each compiled pipeline directly in its own entry.
An older unfinished compilation cannot retain a later completed handle in an
ordered result window. Remove that window, its serial publication owner, the
sequence/lease field and unpublished-result shutdown callbacks. Workers borrow
the original bounded request slot through creation and Store; destruction occurs
before the lease is finished. No additional request move, result buffer, payload
copy, allocation, release diagnostic, GPU readback or frame pacing is introduced.
The 4096-slot SPMC admission ring still provides bounded backpressure. This is
not a solution to waiting for the draw's own required compiler job.

Both Store callbacks already use per-entry atomic publication and multi-producer
placeholder retirement. Command submission and GPU completion order stay intact.
A previously plain upcoming-submission counter was read by compilation workers
while the command owner advanced it. Use common atomic initialization/acquire
loads/release stores; keep one writer, with no locked read-modify-write increment.
Completed-submission bookkeeping remains command-owner-only. This removes the
identified non-atomic data race; it is not proof of all renderer race freedom.
Stop/join creators before destroying entry-owned handles and retirement storage.
