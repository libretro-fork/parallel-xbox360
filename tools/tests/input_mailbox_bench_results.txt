Input adapter benchmark, 4 November 2026
Baseline: 446c545f, actual libretro_hid.cc/.h from git archive.
Candidate: pinned C89 snapshots, fixed keystroke storage and frontend rumble.
Host: Windows, AMD Ryzen 9 9950X3D. No process affinity pinning.
C89 driver, minimal C++ ABI bridge to the actual adapter. MSVC /O2 /MD; MinGW GCC 16.2 /O3 -mavx.
Serial old/new/new/old order; five batches per process, 1,000,000 reads and 50,000 polls per batch.
Rumble/hotplug/key/mapping validation precedes timing. Frontend callback reentry is validated on the candidate.
All timings are ns/call. Uncontended synthetic cases, not retail FPS, end-to-end latency or multi-reader throughput.
Poll cases use each implementation's repeat clock, so generated repeat event counts need not match.
The irreducible candidate read includes immutable-slot pin/release atomics plus guest-format stores; no hardware-limit claim.
