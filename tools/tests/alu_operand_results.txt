Correctness:
- Actual packed VS/PS programs cover vector ADD, single-source scalar ADD and
  constant/register scalar ADD, abs/negate combinations: 24 literal goldens.
  The exact old implementation produces -3 instead of +3 for vector abs.
- C89 source-reader tests cover 512 borrowed pointer identities, relative/window/
  bank/overflow bounds, eight literal rotation/broadcast anchors, and 40960
  swizzle/modifier/FTZ cases for scalar and vector readers. Include signed zeros,
  denormals, infinities and NaN payloads. Linux ASan/UBSan and MSVC /TC /W4 /WX.
- Minimal typed C++ glue sets up the actual interpreter; runtime source reading,
  packed programs, output goldens and private timing driver are C89.

Implementation and limits:
- Constant-bank ownership stays on the interpreter owner. Views are checked,
  read-only and instruction-scoped; invalid constant windows produce zero.
- Scalar reads load only their selected word. Vector reads hoist shared masks
  once into their existing decoded-operand destination. Alias-safe 4-byte bit
  loads retain all modifiers and signed FTZ behavior. No new allocations,
  locks, caches, release clocks, instrumentation or logging.
- The old std::array return may already have been optimized away in some paths.
  Removing its materialization contract does not prove 16 bytes less physical
  memory traffic. Required decoded coissue snapshots/export copies remain.
- This is a CPU reference/draw-extent correction, not GPU shader optimization
  or a ready generic renderer. Full CF/fetch/stage/ROP fallback coverage and
  zero frame-critical compilation/wait counts remain unresolved.

Matched native interpreter component comparison:
- Ryzen 9950X3D 16C/32T; MSVC Release /MD /O2. Same source/build paths,
  full exact-parent and candidate libraries; no mixed-header object override.
- Persistent owner outside timing; actual SetShader/Execute for 1 or 6 ALU
  instructions. Each case has 7 alternating/reverse-order process pairs,
  128 batches of 1024 executions/process; 896 raw batches/variant/case.
- CPU affinity logical CPU4 when permitted, otherwise first permitted CPU.
  QPC elapsed time; direct output checksum equality. No game or disk caches.
- Predeclared relative + absolute ns/execute gates (both must be exceeded):
  median 10%/2ns, p95 and p99 25%/5ns, maximum 50%/10ns. Unchanged after failures.
  First per-lane vector-reader experiment failed p95 and was rejected. Its

  bench-measurements. Hoisting vector modifiers resolves that regression.
- Revised reader has zero component threshold alarms. Some short-case p95
