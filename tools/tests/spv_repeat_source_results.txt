Parent: complete b40bab43d38485f19fcc26bbd874b93b7494be51 sources.

C89 logical sources borrow either contiguous caller words or one scalar ID plus
a repetition count. Repeated mode never pretends that the scalar has an N-word
C array extent. Hashing, exact-key comparison and packet emission consume this
source directly; there is no intermediary member array or retained caller view.
The repeated hash equals the existing contiguous-key hash, so ordinary-view and
repeated factories share constant identity in either insertion order.

SpirvBuilder::smearFloatConstant and specialization-mode Builder::smearScalar
now use repeated sources. Composite comparison uses the single-index extract
overload, and extract specialization operands/literals borrow their scalar
arguments rather than creating vectors. The multi-index overload borrows the
caller's existing indices. No new capability requirement is introduced.

Replicated-composite selection, compressed one-member encoding, extension/cap
ordering, cooperative-vector handling, ordinary aliases and uncached spec
composites/structs keep existing behavior. Oversized physical constant payloads
are rejected before hashing/emission; a compressed source checks its physical
one-member count. Final packet-to-contiguous-module assembly still copies.
This removes staging arrays, not all compilation copies or allocations.

The first coordinator implementation copied its source descriptor twice through
an extra ABI call (observed GCC assembly) and regressed ordinary constant
construction about8-9%. That version was not pushed. The two producer adapters
now inline the shared type/feature coordinator under MSVC/GCC-compatible
compilers, removing those intermediary metadata copies and specializing source
mode. The algorithms and packet writer remain MSVC-compatible C89, with thin
C++ ownership/exception/type coordination. Final ordinary costs are below.
