Parent: complete 56220d16ef8c16a7d88b7b8a6cd87495a4250c00 sources.

A whole-runtime reference audit found no calls to the standalone postprocessor
outside its own definitions/declarations. The libretro generators already emit
required capabilities, extensions and same-block sampled images themselves.
Remove SpvPostProcess.cpp, its public APIs and typed canonical-dead-block rewrite
helpers, rather than optimizing their temporary hash containers. Remove the
postprocessor-only decoration alignment/alias/pruning helpers, their fixture,
and the unused active field. C89 decoration prefixes shrink 12 -> 8 bytes;
serialization unconditionally borrows every stored decoration. Eight-byte
payload alignment means even wire lengths save eight padded bytes per record;
odd wire lengths retain the same padded size. No global RSS reduction is inferred.

Live Function::dump no longer constructs/passes std::function. A plain function
pointer borrows a two-pointer output/plan context for synchronous readable-order
serialization. The typed visit bridge catches exceptions, returns failure to
the C89 walk and rethrows afterwards, retaining output recovery behavior. The
context never escapes the call. Graph, words and plan nodes are borrowed;
there is no new copy of labels, graph edges, packet data or a callback owner.
C89 traversal algorithms and encoded packet layouts remain unchanged. Final
module assembly still copies packet spans into the required contiguous buffer.

The deleted postprocessor is excluded from upstream merges and removed from
CMake sources; static Make source discovery excludes the absent file. The Make
archive is rebuilt from its response list, so no stale removed member remains.
Historical complete-revision tests optionally compile their own postprocessor
through spv_compile_revision; its source/header always belong to that baseline.
This harness compatibility does not add the file to the current core build.
Raw-construction fixtures replace dormant inference/pruning/cloning fixtures.
The sampled-image test explicitly constructs a sampled image in each consumer
block. The obsolete partial-source module comparison is now a complete-revision
comparison, avoiding a mixture of historical IR and current C storage layouts.
