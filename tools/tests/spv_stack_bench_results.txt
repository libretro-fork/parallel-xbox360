Windows x64 GCC 16.2 -O2; native MSVC and WSL ASan/UBSan checked separately.

Three std::stack/default deque owners (debug scope IDs, switch merge pointers,
and LoopBlocks) are replaced by borrowed typed views over C89 retained pages.
Pages hold 64 frames; frame areas align to 64 bytes and strides round to eight
bytes. Growth links another page without moving or copying live frames. Pops
reuse earlier slots; reset keeps high-water pages until arena close. Count/size
arithmetic, incompatible strides and growth failures are checked. Cold compiler
setup reserves one page per stack. This reserves capacity, not a guarantee of
physical prefaulting for every payload page. Deeper stacks can still allocate.

LoopBlocks contains four Block references and makeNewLoop returns LoopBlocks&.
A reallocating contiguous replacement would invalidate callers' outer references
when nested loops grow. The paged replacement preserves those addresses. Blocks
are still created in the same ID order; the reference aggregate constructs once,
directly in its final frame, without a temporary LoopBlocks copy. A size assertion
protects the cold reservation against ABI/layout drift. Scope IDs and switch
pointers use explicit typed placement construction. The thin C++ view requires
nothrow copying, trivial destruction and alignment <=8. All allocation, paging,
logical retirement and reuse algorithms are C89; no type-punned pointer arrays.

Module ownership precedes all typed stack views in field/declaration order.
Builder destruction retires frames before releasing functions; module cleanup
also retires frames before orphan IR cleanup. C arena end covers raw callers.
Only trivial values may occupy frames, so bulk retirement needs no user callback
or resource destructor. Empty resets return immediately. ASan poisons popped and
reset frames; new pushes unpoison only their slot. Arena close unpoisons/free
pages through the same C allocation hooks as growth. No new shutdown callback,
thread, synchronization, logging or release profiling counter is introduced.

Each fixture falls from seven to one counted allocation per module (85.71%
fewer), and 1768 ->40 requested bytes (97.74% fewer). This is a fixture result,
not an assertion that every real shader now allocates once: other metadata,
decoration/string containers, larger working sets and driver paths still allocate.
The remaining request in these fixtures is the capability-set node.

Tiny function construction median falls 53.35%; 71-function construction falls
4.74%; the largest falls 1.16% with overlapping ranges, so remains comparable.
The small constant case falls 12.34%; medium/large cases fall 1.77%/0.67% with
overlapping ranges, so are comparable. Retained storage rises 3477 bytes in all
cases; peak tracked storage rises 1749 bytes after removing the transient deque
buffers. No total compilation, driver, gameplay/FPS, RSS, cache-miss or register-
spill improvement is claimed. Serialization throughput was not separately timed.
