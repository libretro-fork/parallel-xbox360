Test method
-----------
Generate sixteen real vertex shaders through Shader::AnalyzeUcode and the
production SpirvShaderTranslator. Portable feature settings select the existing
integer RTZ fallback, without assuming optional native float controls. The guest
ALU reads explicit c0.y=1.0; input GPRs start zero just as they do on the GPU.
Golden values (3,5 or2) are independently asserted and checked by the existing
CPU ShaderInterpreter. Uniform bool input is explicitly varied and predicate
true is produced by a real guest setp instruction.

Add only SPIR-V TransformFeedback capability, Xfb execution mode, and buffer/
stride/member-offset annotations to the existing gl_Position output. IDs, CFG,
ALU instructions and the vertex postamble remain intact. System constants use
W-as-W, unit NDC scale and zero offsets, so the postamble preserves the expected
four words. A discard-only graphics pipeline runs one vertex, with no fragment
stage, image allocation or CPU emulation of emitted SPIR-V. Capture16bytes into
a persistently mapped buffer and compare exact bits plus all4080 guard bytes.
