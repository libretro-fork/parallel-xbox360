Measured float32 properties: RTZ=1, RTE=1, FTZ=0, signed-zero/NaN preserve=1.

Production
----------
Select RTZ independently of FTZ. Reuse the bounded C89 xe_rtz_emit_flush recipe
through a thin scalar/vector typed adapter, with stack constant views. Flush
signed operands/results around uncontracted native ADD/SUB/MUL. Keep the full
integer fallback where RTZ is absent and the native RTZ+FTZ path where supported.
Pixel policy, DXIL, guest audio, frame pacing and cache defaults are unchanged.
No copied shader payload, new compiler arena, diagnostic logging, readback,
thread, sleep or runtime queue is added. Existing translator/driver allocations
remain. Smaller IR is not proof of zero allocation or lower GPU execution time.
