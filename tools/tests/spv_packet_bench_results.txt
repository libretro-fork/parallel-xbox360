C89 encoded instruction packets, 2026-11-06
Parent: complete 66a09e024643ef15502e513e2e8c3619694d19b8 sources.

Production guest/helper instructions now contain a C89 encoded packet instead
of separate opcode/type/result fields plus operand-only storage. The packet
constructs its header, optional type/result prefix and operands in wire order.
Appending an operand updates the encoded word count. Operand patches write
directly to the wire span; ID/literal flags remain separate packed metadata.
No GLSL source parser or new IR is introduced.

Output validates the opcode/16-bit length and borrows the complete packet for
one append into final module storage. It no longer encodes each instruction's
prefix during output. Vulkan still requires a contiguous module in logical/CFG
order, so final assembly copies packet spans. This is not zero-copy module
submission and does not remove the existing control-flow/type ownership graph.

The immutable opcode/type/result prefix already retained in the inline area is
used for metadata queries after heap promotion. No separate query cache, new
allocation or extra copy is added. Prefix size uses two metadata bits. Constants
compare encoded scalar/pair integer representations directly; longer payloads
use memcmp. NaNs, signed zero and specialization distinctions retain bit identity.

Tested x64 sizes remain Instruction64/Block136/Function136/Module88/Builder1504.
The C packet is 56 bytes with the arena tag still at byte12; the existing owner
link completes the 64-byte instruction. Inline operand capacity is 7-prefix:
four with type+result, five with one, six with neither (formerly four for all).
Heap payloads now include their one-to-three-word prefix, adding 4..12 bytes
at equal operand capacity, before pooled padding. Geometric capacities/growth
can also differ because of the larger untyped inline capacity. No universal
memory reduction or absence of growth is claimed. Heap promotion copies the
live span and flags; pooled reset retains high-water pages. Free preserves the
arena tag until typed operator delete retires the record. Borrowed views expire
on growth/free. Opcode/type/result are immutable after initialization.

Measurement method: Windows x64 GCC16.2 -O2, own-revision C/IR sources, same
existing fixtures. All C++ new and C arena/operand/index/plan/output hooks are
counted; allocator headers/free-block retention and driver memory are excluded.
Construction includes cleanup, excludes dump/file I/O; warmed untimed outputs
match. Tracked live storage returns to the initial value after workspace close.
