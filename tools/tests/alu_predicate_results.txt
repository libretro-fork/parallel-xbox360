Predicate control validation (2026-11-10)
========================================
First parent: 74fef36f8380d7d1779dfc0c2e42ce28e234e143.

The raw control validation kernel now handles scalar SETP_EQ/NE/GT/GE, predicate
EXEC/EXEC_END, predicate CALL/JMP and predicated ALUs. Bool clean EXEC/END forms
retain ordinary bool-conditional numerical semantics. One private uint word
retains P0 across clauses, calls and loops; it resets per invocation. No register
frame or context payload is copied. The existing descriptor ABI and shared
160-byte bool/loop view are unchanged.

Scalar comparisons use integer binary32 fields: denormals compare as signed
zero, EQ treats both zero signs equally, NE is true for NaN, and GT/GE reject
NaN. Source swizzles/modifiers precede comparison. SETP writes exact 0/1 scalar
results and retains scalar history even when its destination mask is empty.
An instruction's execution predicate is sampled before its vector/scalar side
effects. An untaken ALU skips opcode/address validation and operand access,
retaining P0, scalar history and registers. An untaken conditional transfer
skips target/stack checks; conditional END terminates only when taken.

The predicate has an independent four-byte word. A packed-word prototype was
correct but slower in measurements and was rejected; static storage density is
not a throughput argument. Independent state preserves partial-export bits
without adding shifts/masks to their existing loads/stores. The selected module
is 7866 words, up from 7558. Arithmetic remains byte-identical at 2855 words;
the original program module remains 6051 words with two independent-operation
reorderings described below. Three functions and three structural loops remain, using only
32-bit integer SPIR-V 1.0 with Shader capability. No GLSL parser, new capability,
per-program module/pipeline or production source-list entry is introduced.

Correctness and semantic negatives
---------------------------------
An additional 1254 untimed predicate replays exercise four comparisons over
twelve binary32 classes: positive/negative zero, smallest positive/negative
subnormal, positive/negative one, positive/negative minimum normal, infinities
and quiet NaNs. Literal truth tables and values accompany native interpreter
comparisons. Scalar swizzles deliberately select among lanes with opposing
predicate outcomes. Both program byte orders are covered.

Cases cover scalar result/history, predicate EXEC and END, CALL/JMP, old-predicate
coissue, skipped unsupported work, untaken invalid targets, clean-hint predicate
preservation and initial state. Adjacent invocations share the same program and
constants but take opposite branches. Predicate changes between partial position
exports must preserve the earlier components and write mask. Export counts are
anchored independently, including the clean-hint case's conditional extra export.

Full coverage: 3771 GPU invocations, 2947 native-reference comparisons, 224 bool,
36 loop and 1254 predicate context replays. Inputs/context remain immutable;
unsupported execution changes only status and preserves output payload/redzones.
The same active pipeline/module and reusable buffers execute every replay.

Deliberately ordered NE fails at round 307, invocation 0 (1 instead of 0 for
NaN). Ignoring ALU predication fails at round 751 (3 instead of 2). A mask-clearing
mutant of the rejected packed prototype fails the new partial-export case at
round 1515 (incomplete output status 4 instead of 1). These are semantic RTX
failures, not compilation/device errors; private mutants are not production code.

MSVC /TC /O2 /W4 /WX, GCC strict C89/ASan/UBSan and official spirv-val Vulkan 1.0
pass. The emitter passes 1000 exact same-owner builds with no additional
allocation and failure/recovery/overflow/close checks. RTX 5090 driver
32.0.16.2101 and llvmpipe LLVM 20.1.2 pass the full selected suite and original
12280 arithmetic/743-program/363-reference suites. All 43 Python guard tests
pass. WARP establishes emitter/unit coverage only, not Vulkan execution.

Limits
------
The extension is functionality work on an unlinked prototype, not a throughput
improvement or a cold-play fix. Driver disk/internal caches are not certified
cold; first-creation and first-use observations remain UNVERIFIED. Completion
includes host/queue service and heterogeneous/cyclic data, not pure GPU time.
Retain runtime-cost debt, register/spill/occupancy uncertainty and all failed or
rejected prototype results rather than treating a passing broad noise floor as
proof of equal performance.

Group-wide predicated loop breaks remain unsupported; per-invocation CPU
behavior alone does not establish their sequencer semantics. Empty-loop effects,
vector predicate pushes, scalar predicate counters, other addressing/ALUs,
fetches, pixel RNE, remaining stages/exports, ROP and valid-work continuations
also remain incomplete. No inaccurate fallback is selected. Actual draw-path
translation, PSO creation and compilation waits remain unresolved.

No installed core, game, live cache, production logging or release clocks were
changed. Private evidence is C:/git/accurate-shader-fallback/predicate-control.
The final selected comparison is paired-final-unpacked/results; paired-final
and paired-packed retain the earlier independent/packed prototypes separately.
