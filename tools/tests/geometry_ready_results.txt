D3D12 native geometry ready ownership — 2026-11-10

Production change
- Replace the geometry mutex/map with the C89 immutable owner cache, using
  libretro-common atomics. Ready hits return the same borrowed final DXIL pointer.
- Cache completed failures. Allocate metadata before invoking the creator;
  publication losers destroy only their own unpublished binary/node.
- Join compiler workers and retire pipeline descriptions before clearing owners.
- Preserve the existing geometry key/options and emitted bytes. Do not alter
  persistent cache schemas, shader defaults, compilation gates or fallback rules.
- Optional dumps use VFS with the exact borrowed byte count. DXIL containers are
  not assumed word-sized; no staging payload or truncating word cast is added.

Limitations
The component tests do not establish correct generic fallback rendering or
loaded-game frame-time behavior. Geometry misses still allocate/emit. Duplicate
cold emission under a publication race remains possible. Vertex/pixel binding
mutexes, draw-side translation/module/PSO creation, blocking queue admission,
compilation waits and inaccurate stand-ins remain unresolved architectural debt.
The fake failed-content unload check does not replace sustained gameplay unload.
Driver caches are not certified cold. No user caches/core/game were replaced.
Procedural shader timings do not exercise the D3D12 geometry-cache hit path and
must not be represented as a measured gameplay speedup from this change.
