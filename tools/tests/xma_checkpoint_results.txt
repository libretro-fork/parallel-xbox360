Native raw XMA history checkpoint
=================================
The direct rwma API captures 256 float history samples per active channel and
versioned scalar state. The ephemeral view borrows decoder storage and is not a
wire format. Restore validates the entire view before mutating either channel.

Executed MSVC C89 and MinGW C89 coverage:
- 24 mono/stereo profiles at 24/32/44.1/48 kHz with previous blocks 128/256/512.
- 192 future synthetic frames match bit-for-bit after seeded overlap restore.
- Incorrect version/rate/channels/flags/previous length, truncated histories and
  a late-channel NaN are rejected without mutation. Signed zero survives exactly.
- This standalone test links native rwma only; no FFmpeg target or bridge.

The separate decoder/owner suites cover pending PCM and transactional 320-owner
restore. This history fixture uses synthetic no-coefficient frames, not gameplay;
it does not implement complete libretro savestates or establish audio cadence.

Reproduce:
  sh tools/tests/run_xma_checkpoint_tests.sh
  tools\tests\run_xma_checkpoint_tests.cmd
The Windows script uses retro-common.lib from XMA_CODEC_BUILD (default
build/windows-native). Set XMA_CHECKPOINT_FLAGS for optional instrumentation.
