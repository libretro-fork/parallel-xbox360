Encoded C89 extension metadata, 2026-11-06
Parent: complete 8b54c209ee164070abff3b03f4a77cce7110d28d sources.

The extension registry no longer owns std::set<std::string> nodes. A reserved
C89 group key owns sorted pointer metadata; each unique name is encoded once
as an active flag plus OpExtension wire words in the existing payload pool.
Lookup compares the owned encoding to borrowed caller text. Output borrows the
wire span, avoiding string re-encoding and temporary instruction storage.
No instruction arena slots or result IDs are consumed.

Disable clears the active flag; re-add reactivates the same blob, avoiding
allocation and re-encoding. Distinct disabled names remain until lease reset;
this bounds churn by unique names per module rather than add/remove count.
Names are copied/encoded once on first insertion, so this is not zero-copy
input ownership. Final module assembly still copies spans into the required
contiguous output. The legacy type/CFG builder remains.

Cold reserve: 16 pointers (128 bytes on tested x64) per workspace, allocated
before compilation. More unique names grow metadata with checked rollback;
payload high-water can grow too. New blobs share the operand payload pool and
can interrupt a previous payload's last-span growth opportunity. Removed-name
storage is not individually reclaimed during a lease. Reset retains pages and
metadata capacity; owner close releases them. No universal RSS reduction or
allocation-free translation claim is made.

Measured GCC x64 Builder shrinks 1504 -> 1456 bytes. Ordinary warmed lookup
fixtures retain 191706 -> 191834 tracked bytes, reflecting the cold pointer
reserve. The replicated fixture retains 191800 -> 191834 tracked bytes; the old
set node/string allocations disappear while encoded words fit existing pages.
Tracked allocations are requested user storage, not allocator RSS/VRAM.

requested bytes; current zero allocations / zero requested bytes. Parent and
current both use the repeated-source API, so these totals isolate the extension
change rather than counting the already-removed staging vector. The other
