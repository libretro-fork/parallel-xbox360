Runtime transfer sample-address foundation, 2026-11-10

Scope: C89 shared emission, raw SPIR-V and native DXIL adapters, CPU metadata
validation/preparation. NOT a complete generic ownership-transfer shader and NOT
connected to rendering. Existing inline shader/PSO creation and waits remain.
No gameplay speed, renderer GPU-cost or cold-play smoothness improvement claimed.

Address rules preserve scale quotient/remainder,1x, native2x,2x on host samples0/3
of4x, and guest4x sample bits. Dynamic division uses CPU-prepared reciprocals and
unsigned multiply-high/correction; there is no shader int64 or variable division
in the address recipe. Fixed record-bound guards in the SPIR-V test use division
by constant record widths. Inverse test inputs are independent of forward output
so paired mistakes cannot hide through a round-trip test. All arithmetic wraps
as u32, matching the existing coordinate operations.

CPU validation rejects zero scales, sample log2 outside0..2 and nonboolean
native2 flags without modifying output. Caller still validates backend-specific
resolution limits and buffer ownership. Emission borrows native IR IDs, adds no
intermediate payload representation, and leaves output records unchanged on
failure. Native writer arenas/output buffers retain their normal allocations;
allocation-free emission glue is not a claim of an allocation-free compiler.

Failure investigation retained privately:
The initial1129-word packed-coordinate selection module passed NVIDIA and WARP
but failed llvmpipe at2x record16385, among42658 mismatching lanes. Disabling its
disk cache did not resolve it. Adding an observable u2 intermediate store made
that module pass; storing unrelated inputs/final output did not. No such store
was added to the production adapter. The current shared integer bit-layout
calculation passes the unchanged oracle/corpus on all three implementations.
An equivalent bitfield-insert experiment also failed and was rejected. Original
modules, disassembly, output logs and intermediate probes remain in the evidence
directory. These observations do not identify a particular upstream fix.
