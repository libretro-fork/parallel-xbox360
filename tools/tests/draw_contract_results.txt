Implementation
--------------
Opt-in C89 fixed atomic counters with compiler TLS thread roles; no allocation,
logging or clocks in accounting. Six roles, three pipeline kinds, ten events.
Default release macros discard all accounting arguments; only the original API
call executes. Snapshot ABI1 requires exact buffer size; reset requires quiescent
producers. Per-word atomic snapshots are not transactionally consistent. Wait
counts are observed waiting predicates, not elapsed time or exact parked waits.
Unknown roles and incompatible snapshot metadata fail closed.

Instrument19 current direct Vulkan/D3D12 module/graphics/compute creation calls,
shared guest translation, native DXIL emitters, pool waits/caller jobs and current
incorrect stand-in/missing-draw branches. Lexical API-site checks reject omitted,
wrong-event and partial-getter wrappers; aliases and future creation APIs need
explicit review. The LINK bin is available; this core has no separate current
program-link API site. Initialization scopes are limited to backend setup;
unclassified threads are conservatively UNKNOWN, not silently initialization.

Nonblocking try_begin checks one reusable slot without moving the cursor on
failure. Typed TryPush refuses missing workers/full storage before constructing
or moving requests. It borrows existing slots and changes no payload storage,
capacity, worker count, completion lifetime or publication ordering. Existing
renderer Push/admission remains blocking until an accurate ready path exists.
Remove two host-tick reads used solely by an already-disabled await diagnostic.

Limits and remaining work
-------------------------
No claim of faster compilation or fixed gameplay stutter. These component,
lexical, instrumented-translator and no-content DLL tests do not establish a
whole-renderer runtime zero-event pass. No loaded-game run, first-correct-frame
measurement, equal-image/progress replay, complete shader-stage fallback,
renderer worker-loss/retirement-exhaustion test or savestate restore acceptance.
No certified empty driver disk/internal cache, no macOS/Android full build.
Counter snapshots contain no durations. Stats-profile timings are not compared
to normal release timings. CI infrastructure can land while these debts remain.

Inline placeholder/real PSO creation, draw-side translation/awaits, blocking
renderer admission, lazy utility pipelines, no-op pixel shaders and skipped
draws remain architectural failures. A ready accurate fallback is the next
required implementation; replacing blocking Push with draw loss is prohibited.

Raw local logs/manifests/CSV samples and sealed object evidence are retained in
C:/git/draw-event-contract and delivered with the mailbox artifact. Hosted CI
also runs the source, unit, instrumented translator and full-profile API checks.
