Production change
-----------------
AluFract previously extracted each software-RTZ lane, flushed it, emitted Floor
and a scalar integer subtract recipe, then constructed a vector. The existing
integer recipe is lane-wise and now accepts vectors. Lend the original vector
to FTZ/Floor/subtract once. Remove the per-component reconstruction and four-ID
scratch array. Preserve input/output signed FTZ, exact finite RTZ arithmetic,
native nonfinite forwarding and uncontracted subtract. Native RTZ and pixel
module bytes remain unchanged. The integer recipe itself is unchanged C89;
production edits are narrow typed SPIR-V builder glue. No new allocation,
copy, value cache, lock, thread, diagnostic or CPU/GPU roundtrip. Existing arena
ownership and lifetimes remain. Shader generation still allocates elsewhere;
this is not an end-to-end zero-copy or allocation-free claim.
