Windows x64 GCC 16.2 -O2 construction fixtures; native MSVC and WSL ASan/UBSan
correctness checked separately. No game, frontend or GPU was launched.

The capability tree becomes a retained sorted uint32 array. Cold startup reserves
64 values (256 bytes); its owner adds 24 bytes. Larger sets grow with checked
allocation, copying only live metadata; interior insertions move suffix metadata.
This is not a claim of copy-free set insertion. Reset retains capacity, and close
releases it through matching C hooks. Zero and UINT32_MAX remain ordinary keys.
Postprocess scans borrow sorted values and membership uses binary search.
Capability and memory-model serialization writes final words without temporary
Instruction objects. The quad specialization helper borrows a four-ID array.

The Vulkan version probe emits 39 words into final caller stack storage. It has
no builder, instruction graph, output vector or heap allocation. Its bound of six
preserves the legacy builder's discarded unreachable ID. Seven versions 1.0..1.6
match legacy bytes exactly and pass spirv-val. This is a startup-path reduction,
not a measured gameplay shader compilation speedup.

functions use long names, 1/71/257 functions, no parameters/linkage; constants use
